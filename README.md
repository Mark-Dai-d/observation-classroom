# 观察物体互动课堂 · 换个位置看世界

面向小学三年级的数学互动教具，帮助孩子理解观察位置、看到的画面与遮挡关系。

## 功能

- 六种物体：小汽车、图案方盒、长方体纸盒、圆柱、球、组合积木。
- 自由观察：拖动改变观察角度，也可以选择正面、右侧、后面、左侧和上面五个固定位置。
- 视角小侦探：看画面猜位置、看位置选画面、相同轮廓多选练习。
- 形状实验室：并排比较不同视角，练习预测、验证和解释。
- 内置课堂指南、全屏、提示、答错重试及离线下载。

## 使用

发布后打开 GitHub Pages 地址即可使用，不需要登录。
也可下载 `index.html`，用电脑 Chrome 或 Edge 打开，断网仍可使用。
所有模型和交互均内置，没有外部脚本依赖。浏览器不支持 WebGL 时自动使用备用绘图。

## 发布设置

本项目是纯静态网页，无需构建或安装依赖。

1. 将所有文件上传到公开仓库根目录，入口文件保持为 `index.html`。
2. 在仓库 **Settings → Pages** 选择 **Deploy from a branch**。
3. 选择 **main** 分支和 **/(root)**，保存并等待发布完成。

GitHub 官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 教学建议

先用实物让孩子换位置观察；再用网页先猜后看；最后离开屏幕做新题。
固定站位采用正投影，方向以 A—E 站位标记为准。圆柱和球可能对应多个相同轮廓的位置，使用多选练习。

公开网址可以直接分享；搜索引擎是否收录及何时收录无法保证。
